# Public Sharing Rules

Public sharing must protect participants before it serves explanation, persuasion, or aesthetics.

This file defines what can be shared from the friend pre-pilot and later project stages.

## Governing question

What project material can be public without turning private body data into public identity data?

## Default rule

Share the method.
Share the code.
Share protocols.
Share anonymized or synthetic traces when useful.

Do not share raw identifiable video by default.

## Never share publicly without separate explicit permission

Do not publish:

- raw friend videos
- faces
- names
- voices
- exact recording locations
- consent forms
- injury histories
- private messages
- participant anecdotes that identify the person
- screenshots where the participant can be recognized

Consent to participate is not consent to public display.

## Usually acceptable

The following can usually be public if reviewed for identifiability:

- protocol descriptions
- capture setup diagrams without participant images
- blank consent templates
- analysis code
- synthetic data examples
- aggregate feature summaries
- anonymized plots of gait-cycle curves
- field reports that discuss what broke without identifying participants

For the friend pre-pilot, use extra caution because the sample is small and participants may be known to the project lead.

## Participant-level traces

Participant-level traces may be public only when all of the following are true:

- the trace contains no name, face, voice, location, or direct identifier
- the participant code cannot be linked from public context
- the trace is necessary for the public point being made
- the participant consent allows this use
- the caption uses condition-bound language

Use captions such as:

> P003, session 1, normal shod condition: right stance cycles show later peak hip extension than left stance cycles.

Do not use captions such as:

> P003 is a spiral type.

## Language rules

Public writing may say:

- "this recording"
- "this condition"
- "this gait cycle"
- "this movement pattern"
- "candidate support-path trace"
- "hypothesis not supported"

Public writing must not say:

- "this person is"
- "this type of body"
- "diagnostic sign"
- "pathological pattern"
- "proof"
- "signature of identity"

## Images and video

Use raw participant video only in private analysis unless a separate public-release consent has been signed.

If a visual example is needed, prefer:

- synthetic skeleton animation
- cropped non-identifying movement trace
- OpenSim-style model rendering without face or clothing
- simulated curve data
- aggregate plot

Do not blur a face and assume the result is anonymous. Body shape, clothing, room, gait, and context can still identify a person.

## Review before publishing

Before anything goes public, ask:

- Does this reveal who participated?
- Does this reveal private health or injury information?
- Would the participant be surprised by this use?
- Does the language classify the person instead of describing the recording?
- Is this detail necessary for the public claim?

If the answer is unclear, keep it private.
