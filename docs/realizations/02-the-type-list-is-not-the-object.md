# The Type List Is Not the Object

Visible walking categories are provisional language. The object is the step, the support path, and the gait-cycle data.

## The distinction

A type list is a naming tool. It helps an observer remember recurring impressions: stiff, loose, rotated, delayed, heavy, springy, collapsed, controlled.

Those words may be useful at the beginning. They are not the research object.

The research object is not the name.
The research object is not the person.
The research object is the step under a condition.

## Why the type list is dangerous

If the project starts by naming people, the analysis will try to justify the names. The model will learn the observer's labels. The repo will become a system for making informal impressions sound technical.

That would fail the governing question.

The point is not to prove that a type list was right. The point is to ask whether the visible impressions correspond to recurring gait-cycle structures.

## What the type list can do

A type list can propose hypotheses:

- This recording appears to route load mostly through the lateral side.
- This left stance appears to stabilize later than this right stance.
- This participant may change strategy under speed.
- This barefoot condition appears to remove a pattern visible in shoes.

Each sentence must remain testable. If a word cannot be connected to features, timing, asymmetry, or curves, it stays observational language.

## What replaces the type list

The project replaces fixed type labels with a chain:

Observation proposes.
OpenCap translates.
AI sorts.
Measurement decides.

The type list belongs only in the first step. It can help make the blind observation memo explicit before processing. It cannot decide the result.

## The useful surprise

The data may show:

- fewer families than the observer expected
- more families than the observer expected
- no stable families
- clusters organized by speed or footwear
- strong left-right differences within a person
- clear repetition within conditions but not across conditions

Any of those outcomes is better than forcing a type list onto the data.

## Working rule

Write provisional observations in condition-bound language.

Then ask:

> What trace would have to appear in the gait-cycle data for this observation to survive?

If no answer can be given, the observation is not ready to become an analysis claim.
