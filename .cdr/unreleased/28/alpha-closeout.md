### Pattern: Read-before-Write retry friction in long incremental-section authoring cycles

**Context.** `cdd/alpha/SKILL.md §2.5` requires incremental section authoring (each self-coherence section committed and pushed separately to survive stream timeouts). The harness Write/Edit tools require a prior Read of the file in the same session. Across cph#28, α authored 8 self-coherence sections + the multi-section field-report-01 rewrite (Overview / Falsification Assessment / Segmentation Status / L-side recovery / Recommendation / Appendix A) + status-surface updates on PROJECT/ROADMAP/CHANGELOG + the regenerated `analysis/feature-summary-zeroth-pilot.md` — each of which required re-reading the prior file state before appending or editing. Session-scope Read cache is invalidated by intervening writes, context compaction events, or branch switches, surfacing as "must Read before Write" tool errors that consume turns.

**Friction.** Moderate, distributed across the cycle's high turn count. Each Read-before-Write retry adds one turn; no individual retry is fatal but the aggregate cost is observable. The §2.5 incremental-write discipline does mitigate the worst case (no partial-stream loss on timeout) but multiplies the Read-cache invalidation surface for cycles with many sequential file touches.

**Pattern surface.** Long incremental-section authoring cycles (multi-section self-coherence + multi-section field reports + multiple status surfaces) are a recurring class for analysis-mode and design-and-build-mode cycles. Surfaces affected: `cdd/alpha/SKILL.md §2.5` (incremental-write discipline — the tradeoff between Read-cache invalidation cost and stream-timeout safety is implicit in the current rule; the friction is observable but the discipline is on net correct for the timeout property it protects); harness-level (Read-cache semantics — out of scope for cdd skills, named here for pattern continuity); `cdd/gamma/SKILL.md §Cycle scope sizing` (cycle-scope sizing for cycles with N self-coherence sections × M file touches is observable from prior cycles; γ may use turn-count as a sizing signal).
