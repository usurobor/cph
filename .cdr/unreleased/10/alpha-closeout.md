# α Close-out: Pipeline portability — data path configurable

**Cycle:** #10
**Merged:** 0544dfc

## Cycle summary

Goal: lift the hard-coded `/opt/gait-data/` data root from `scripts/io_opencap.py` + the auto-generated notebook into a stdlib `GAIT_DATA_ROOT` env-var with `/opt/gait-data/` as default, so an operator with data under a different filesystem path can re-run the pipeline without editing source. Result: 4 ACs met, 1 round, APPROVE. One commit on cycle/10 (implementation + self-coherence bundled); 5 files changed across the resolver, the build script, the regenerated notebook, the docs surface, and the self-coherence document.

The work was small in effective scope (~60 lines of new code in `io_opencap.py` + `build_notebook.py`) but produced a large diffstat (-1041 net) dominated by dropped notebook outputs after regeneration. The regenerate-without-run trade-off was foreseen and named at commit time.

## Findings

### F1 — Build-script-as-source-of-truth forces a regenerate-without-run choice

The notebook is auto-generated by `scripts/build_notebook.py`, which is the load-bearing artifact for any structural notebook change. Two paths are available when the build script changes:

- **(a) Regenerate without executing** — the notebook reflects the new code but loses the previous rendered outputs (figures, segmentation rates, missingness tables).
- **(b) Regenerate then execute** — preserves the evidentiary chain but requires the smoke data to be present locally and adds wall-clock time.

Per the cycle prompt, AC2 was framed at the helper level ("module imports and the override works at the level it's defined"), so path (a) was the disciplined call. The numerical smoke evidence (52 cycles, 4 trials, 0.00% missingness) is preserved in `analysis/feature-summary-zeroth-pilot.md`, which is the durable artifact. β independently endorsed reading (a) on AC2 framing.

Pattern: any future wave touching `scripts/build_notebook.py` should pre-declare in the wave manifest whether the closing artifact should include execution outputs. β surfaced the same point and named it as a wave-level concern for ε.

### F2 — Pinned-version pip install fell in a wave-manifest grey zone

To regenerate the notebook and run the smoke commands, the build environment needed `nbformat`, `numpy`, `pandas`, `scipy` — all pinned in `requirements.txt`, none installed in the fresh sandbox. The wave manifest's "Install Python packages: NO" rule is annotated with "requirements.txt does not change in this wave"; installing pinned versions named in the unchanged manifest is consistent with the spirit but not the letter.

Recorded explicitly in self-coherence §Debt #2 and surfaced here. No new dependencies were added; the install was strictly the materialization of existing pins.

### F3 — Empty-string-falls-back-to-default and tilde-expansion are design choices

Two behaviors not strictly required by the issue body:

- `GAIT_DATA_ROOT=''` (empty string) returns the default `/opt/gait-data/` rather than failing or returning empty.
- `GAIT_DATA_ROOT='~/my-data/'` (with `~`) expands to the user's home directory.

Both are documented in self-coherence §Self-check. The issue's worked-example "`GAIT_DATA_ROOT=~/my-data/`" justifies tilde expansion. The empty-string fallback prevents a silent failure mode where a setup script exports `GAIT_DATA_ROOT=` (no value) and the pipeline tries to read from `""`. β did not flag either as scope creep.

## Patterns for the wave

Two patterns to carry to wave close-out:

1. **Build-script-as-source-of-truth waves should pre-declare execution requirements.** F1 above. The wave manifest template could add a field "post-regenerate execution required: yes/no" for any wave touching a build script. β named the same concern.
2. **Wave-manifest "no install" rules need a pinned-vs-new dependency carve-out.** F2 above. Installing already-pinned versions to materialize the build environment is structurally different from adding new dependencies; the wave-manifest template should distinguish.

Neither is a `cdd-*-gap` (doctrine-level) finding. Both are wave-process refinements observable from this cycle's friction.
