# Blind Observation Memo

This is a template for observation before OpenCap processing.

Complete it after recording and before viewing processed curves, extracted features, clusters, or left-right statistics.

Do not edit the memo after processing. Add later comments in a separate comparison section or field report.

## Purpose

The memo captures what the eye thought it saw before measurement.

It is not a diagnosis.
It is not a type assignment.
It is not ground truth.

Its value is comparison with processed gait-cycle data.
