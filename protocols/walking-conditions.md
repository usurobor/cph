# Walking Conditions

This file defines the walking conditions used in the friend pre-pilot.

## Governing question

Which conditions are varied so the project can see whether movement patterns persist, change, or disappear?

## Condition rules

Each condition should change one meaningful factor at a time when possible.

Always record:

- participant code
- session
- trial id
- footwear
- speed instruction
- surface
- capture notes

Do not combine too many changes in one trial. A "fast barefoot tired after exercise" condition is hard to interpret unless those factors are intentionally being tested.

## Core conditions

### Normal shod

Instruction:

> Walk at your normal comfortable pace.

Purpose:

Establish a baseline for that session. This is not the participant's true walk in every context. It is normal walking under the recorded condition.

### Slow shod

Instruction:

> Walk slower than your normal pace while still walking continuously.

Purpose:

Test whether candidate patterns depend on speed or remain visible when timing changes.

### Fast shod

Instruction:

> Walk faster than your normal pace without running.

Purpose:

Test whether candidate patterns become clearer, disappear, or reorganize under higher speed.

### Normal barefoot

Instruction:

> Walk at your normal comfortable pace without shoes, if that feels safe and comfortable.

Purpose:

Test whether shoe condition changes the measured pattern.

Skip this condition if the surface is unsafe, the participant is uncomfortable, or barefoot walking would create privacy or hygiene problems.

## Optional conditions

### Repeat normal shod

Repeat normal shod after other trials.

Purpose:

Check whether the baseline is stable within the same session.

### Repeat session

Repeat the same core set on another day if possible.

Purpose:

Check whether patterns survive ordinary day-to-day variation.

### Attention condition

Only use if the core capture is already stable.

Example instruction:

> Walk at your normal pace while counting backward by threes.

Purpose:

Test whether attention changes the movement pattern.

Do not add this condition if it makes the session too long or confusing.

## Rest and safety

Allow rest between trials.

Stop or skip conditions if the participant reports pain, fatigue, dizziness, discomfort, or concern about being recorded.

Record fatigue or discomfort as context. Do not treat it as a nuisance variable to hide.

## Naming

Use condition names consistently:

- `normal_shod`
- `slow_shod`
- `fast_shod`
- `normal_barefoot`
- `repeat_normal_shod`
- `repeat_session_normal_shod`
- `attention_normal_shod`

Condition labels are analysis variables. Changing names later makes comparison harder.
