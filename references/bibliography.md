# Bibliography

This bibliography collects the key references for the support-path project.

It is not exhaustive. It should grow only when a source is actually used by the concept, instrument, protocol, or analysis work.

## OpenCap

Uhlrich, S. D., Falisse, A., Kidzinski, L., Muccini, J., Ko, M., Chaudhari, A. S., Hicks, J. L., & Delp, S. L. (2023). OpenCap: Human movement dynamics from smartphone videos. *PLOS Computational Biology, 19*(10), e1011462. https://doi.org/10.1371/journal.pcbi.1011462

OpenCap core repository. Main OpenCap processing pipeline. https://github.com/opencap-org/opencap-core

OpenCap processing repository. Processing tools for kinetics and related analysis. https://github.com/opencap-org/opencap-processing

OpenCap website. https://opencap.ai
